# simple-number-demo

This repository now holds the most basic possible Python program for experimentation with autonomous agents. It prints the numbers 1 through 10 to standard output.

## Requirements
- Python 3.9+ (comes with macOS 14+ by default)

## Usage
From the project root, run:

```bash
python main.py
```

You should see the numbers 1, 2, ..., 10 each on their own line.

## Next steps
- Use this minimal script as a sandbox for evaluating autonomous coding agents.
- Extend `main.py` however you like; it currently has no dependencies or frameworks to get in the way.
